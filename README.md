# Toolbox 2.0

Zeta용 유저스크립트 중심 플로팅 런처입니다.

## 현재 상태
**2.0.0-alpha.1 (초기 개발 버전)**. 기존 도구주머니를 대체할 준비가 끝난 버전이 아닙니다.

## 설치
[toolbox.user.js](./toolbox.user.js)를 Tampermonkey에 등록합니다. 현재는 단일 파일로 동작합니다. 추후 경량 로더와 원격 본체를 분리할 예정입니다.

## 구현된 기능
- 흰 배경과 세이지 그린 포인트
- 선물 박스형 플로팅 버튼 (초록: 수납 가능 / 회색: 잠금)
- 길게 누르기: 수납 잠금 전환, 짧게 누르기: 패널 열기, 드래그: 위치 이동
- 도구 버튼의 CSS 선택자를 저장하고 DOM 재생성 시 다시 숨기는 기본 수납 기능
- 수동 북마클릿 등록 및 실행
- 모바일 패널 크기 조절

## 아직 구현하거나 검증해야 할 기능
- 기존 도구주머니의 북마클릿 및 설정 데이터 안전 이전
- iframe별 도구 발견/실행 브리지 (특히 교차 출처 iframe)
- Shadow DOM 동적 변경의 효율적인 추적
- 사용자별 도구의 안정적인 식별자 (현재는 CSS 선택자 기반이므로 오탐/충돌 가능)
- 기존 도구주머니의 화면/키보드 보정, 세부 편집 및 부가 기능
- 실제 Zeta 모바일 환경 테스트, 성능/충돌 테스트
- GitHub 원격 본체를 불러오는 경량 Tampermonkey 로더

## 주의
기존 도구주머니와 **동시에 실행하지 마세요**. 이 버전은 이전 데이터를 삭제하지 않지만, 자동 이전도 하지 않습니다. 외부 유저스크립트의 실행 자체를 중단하는 것이 아니라 화면의 런처 버튼을 숨깁니다. 수납 모드에서는 후보 버튼을 눌러 등록합니다.

## 데이터
Toolbox 자체 설정은 사이트의 `localStorage` 내 `toolbox-v2-state`에 저장됩니다. 기존 도구주머니의 저장 키와 분리되어 있습니다.
