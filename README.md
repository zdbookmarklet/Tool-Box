# Toolbox 2.0

Zeta용 유저스크립트 중심 플로팅 런처입니다.

## 설치 (로더/본체 분리)
1. [toolbox-loader.user.js](./toolbox-loader.user.js)를 Tampermonkey에 설치합니다.
2. 제타 페이지를 새로고침합니다.
3. 이후 기능 수정은 [toolbox.js](./toolbox.js)에 반영됩니다. 로더는 실행 시 GitHub 최신 본체를 요청하므로 재설치가 필요하지 않습니다.

### 파일 구성
- `toolbox-loader.user.js`: GitHub에서 본체를 다운로드해 현재 프레임에 주입하는 경량 로더
- `toolbox.js`: 툴박스 본체
- `toolbox.user.js`: 이전 파일명을 쓰던 설치자를 위한 호환 로더 (새 설치에는 권장하지 않음)

**주의:** 로더 파일은 둘 중 **하나만** 설치하세요. 기존 도구주머니도 동시에 켜지 마세요. GitHub 접근 실패, CSP/프레임 주입 제한 시 실행되지 않을 수 있습니다.

## 현재 상태
**2.0.0-alpha (개발 중)**. 기존 도구주머니를 완전히 대체하는 안정판이 아닙니다.

## 현재 기능
- 흰 배경과 세이지 그린 포인트
- 선물 박스형 플로팅 버튼 (초록: 수납 활성 / 회색: 잠금)
- 길게 누르기: 수납 잠금 전환, 짧게 누르기: 패널 열기, 드래그: 위치 이동
- CSS 선택자 기반 버튼 수납 및 DOM 재생성 시 다시 숨기기
- 북마클릿 수동 등록 및 실행
- 모바일 패널 크기 조절

## 미구현 / 검증 필요
- 기존 도구주머니 저장 데이터 안전 이전
- iframe별 도구 탐색 및 실행 브리지
- 동적으로 생성되는 Shadow DOM의 효율적인 추적
- 유저스크립트별 안정적인 식별자 (CSS 선택자 충돌 가능)
- 화면/키보드 보정 및 기존 세부 기능
- 제타 모바일 실환경 검증, 성능/충돌 검증

## 데이터
`localStorage`의 `toolbox-v2-state`에 설정을 저장합니다. 기존 도구주머니 데이터는 자동 이전하지 않습니다.
